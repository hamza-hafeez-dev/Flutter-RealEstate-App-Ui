# Flutter Real Estate App UI

A Real Estate mobile app UI built with Flutter. The project includes an onboarding flow, login and sign-up options, and a home screen for exploring property listings.

I built this project to practice Flutter UI development, screen layouts, and creating a consistent design across multiple screens.

## Preview

![Real Estate App UI Preview](preview/real-estate-app-preview.png)

## Screens Included

- **Splash Screen** — App branding and launch screen.
- **Onboarding Screens** — Introduces the app and its main features.
- **Welcome Screen** — Provides Google and Facebook sign-in options, along with account creation.
- **Home Screen** — Displays property listings, a search bar, and navigation options.

- Clean and modern real estate interface

## Getting Started

Make sure Flutter is installed on your system.

1. Clone this repository:

   ```bash
   git clone https://github.com/hamza-hafeez-dev/Flutter-Real-Estate-App-UI.git
   ```

2. Open the project folder:

   ```bash
   cd Flutter-Real-Estate-App-UI
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```

## Note

This project focuses on the UI. Authentication, property data, and other backend features may require additional implementation.
